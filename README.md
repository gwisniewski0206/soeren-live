# søren *live — Astro

Modern static build of the søren *live site: the original canvas engine wrapped in
Astro, with real routes for shareable URLs + SEO, self-hosted fonts (Archivo via
@fontsource), and external assets. Client-side navigation is instant (History API),
so the audio player keeps playing while you browse; direct URLs / refresh load the
correct page and each route ships its own <title>/<meta>/hidden text for crawlers.

## Routes
/  ·  /bio  ·  /live  ·  /music  ·  /booking

## Develop
    npm install
    npm run dev        # http://localhost:4321

## Build & deploy (GitHub Pages)
    npm run build      # outputs ./dist

`.github/workflows/deploy.yml` builds and publishes on every push to `main` (or by hand: Actions → deploy → Run workflow).
One-time setup: repo Settings → Pages → Source: **GitHub Actions**.

- Before a custom domain is set, the site lives at `https://<user>.github.io/<repo>/`; the workflow passes that
  base path to Astro, and every link, image and audio URL follows it.
- Custom domain: Settings → Pages → Custom domain `soeren.live` + the DNS records GitHub shows. No CNAME file needed
  (ignored for Actions deployments). The next deploy then builds for the root.
- Limits: a published site may be at most 1 GB (the workflow fails with the size if it gets close) and gets
  ~100 GB traffic/month (soft). At 160 kbps that is roughly 13 hours of audio in total.
- Audio is not encoded in CI: run `npm run audio` locally and commit the result.

## Music: adding a recording
1. Put the master (wav, flac, mp3 …) in `audio-src/` — this folder is not committed.
2. Add one row to `src/data/music.csv`:

       id,title,artist,type,date,venue,city,source,cover
       goldener-salon-2024-11-23,goldener salon · live,søren,live,2024-11-23,goldener salon,,goldener-salon-2024-11-23.mp3,

   - `id`: lowercase a-z, 0-9, "-" — becomes the URL `/music/<id>`
   - `artist`: `søren`, `rangø` or `sven miesner`
   - `type`: `live` or `single`
   - `date`: `YYYY`, `YYYY-MM` or `YYYY-MM-DD` (newest first on the page)
   - `venue`, `city`, `cover` may be empty; `cover` is a path under `public/` (lock-screen artwork)
   - fields with a comma go in double quotes
3. `npm run audio` (needs ffmpeg) — writes `public/audio/<id>/` (HLS: playlist + 6 s AAC segments)
   and duration + waveform into `src/data/audio.json`. Only new or changed masters are encoded;
   `npm run audio -- --force` re-encodes everything, `npm run audio -- <id>` one row.
4. Commit `src/data/music.csv`, `src/data/audio.json` and `public/audio/<id>/`.

A row whose audio has not been built yet is left off the site. A broken row fails `npm run build`
with its line number. Rough size: 160 kbps ≈ 72 MB per hour of audio in the repo.

Deep links: `/music/<id>?t=41:20`. Filters are in the address: `/music?artist=rangø&type=live&year=2025&q=hamburg`.

## Structure
- src/engine.js          the canvas engine (artwork, morphs, photo blob), music list and player (queue, HLS)
- src/data/music.csv     the music table · src/data/audio.json generated by `npm run audio`
- src/lib/music.js       table parser shared by the site and scripts/audio.mjs
- src/layouts/Base.astro shell markup + <head> SEO + font imports
- src/pages/*.astro       one file per route (SEO meta + hidden crawlable text)
- src/styles/site.css     all styles
- public/img/*            photos + masks
- public/media/*          live-page videos (mp4)
- public/audio/<id>/*     HLS audio, generated
- public/_headers         Cloudflare Pages caching for the audio

## Notes
- Fonts are bundled locally (no Google Fonts request).
- Line style: smooth by default; `?lines=pixel` on any URL shows the original pixel look, `lines` in the CFG block of src/engine.js sets the default.
- Dark mode: follows the device setting until a visitor uses the light/dark toggle (left of en/de); the choice is kept in the browser. Colours: `--ink`/`--paper` in site.css, `applyTheme()` in engine.js.
- Photo credit and booking address live in the CFG/STR blocks in src/engine.js.
